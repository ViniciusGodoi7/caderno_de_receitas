# 🍳 Livro de Receitas

Aplicativo mobile desenvolvido com Flutter para visualizar, organizar e cadastrar receitas culinárias de forma simples e prática.

## 📱 Sobre o projeto

O **Livro de Receitas** é um projeto desenvolvido para praticar o desenvolvimento de aplicativos utilizando Flutter e Dart. A proposta é criar um espaço onde o usuário possa encontrar suas receitas favoritas e consultar os detalhes de cada preparo.

## ✨ Funcionalidades

- 📖 Visualização de receitas.
- 🔎 Consulta dos detalhes e modos de preparo.
- ❤️ Marcação de receitas favoritas.
- ➕ Cadastro de novas receitas.
- 🗑️ Exclusão de receitas.
- 🎨 Interface simples e intuitiva.

## 🛠️ Tecnologias utilizadas

- **Flutter** — desenvolvimento da interface mobile.
- **Dart** — linguagem de programação.
- **Material Design** — componentes visuais do aplicativo.

## ▶️ Como executar o projeto

### Pré-requisitos

- Flutter instalado.
- Dart SDK.
- Visual Studio Code.
- Extensões Flutter e Dart instaladas no VS Code.

### Passo a passo

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra a pasta do projeto no VS Code.
3. Abra o terminal integrado.
4. Execute o comando para instalar as dependências:

```bash
flutter pub get
```

5. Execute o aplicativo:

```bash
flutter run
```

Para gerar o APK de lançamento, utilize:

```bash
flutter build apk --release
```

O arquivo APK será gerado, normalmente, no caminho:

```text
build/app/outputs/flutter-apk/app-release.apk
```
